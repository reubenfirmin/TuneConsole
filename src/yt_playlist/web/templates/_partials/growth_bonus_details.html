Your past listening · Google Takeout

Add the music you’ve played on YouTube Music before, so TuneConsole can get to know you sooner. It also learns from what you play now.

Richer music details · Last.fm

Last.fm has better genre labels than the free, public sources we use by default. You can register for a free API key, a code that lets TuneConsole ask Last.fm about songs. Those genre labels help improve your recommendations over time.

To find genres, TuneConsole sends Last.fm song and artist names. It doesn’t post what you listen to on your Last.fm profile.

Stories behind the records · DeepSeek

DeepSeek can write a short AI introduction to an album when you open it.

It’s very cheap: with the default daily limit, these introductions should cost well under $1 a month. You can set your own daily limit in Setup.

Its API key is a code that lets TuneConsole use your DeepSeek account. We send only the artist, album title and year.

Save a playlist, heart songs and keep listening to earn these optional achievements.
