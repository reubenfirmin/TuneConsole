Recognized genre tags

Choose which MusicBrainz, Last.fm and Discogs tags can be used as genres. Defaults combine MusicBrainz genres with curated names and equivalent tags. A tag must appear in the provider's metadata to match; adding it here does not assign it to songs.

Changes affect future metadata matching. Removing tags or resetting the list does not change genres already saved on songs. Accepting non-genre tags can reduce recommendation quality.
