# 4Q Emotion Dataset

Source: [Coimbra dataset catalogue](http://mir.dei.uc.pt/downloads.html).
Download: [original audio and metadata ZIP](http://mir.dei.uc.pt/resources/MER_audio_taffc_dataset.zip).
Acquired copy: [audio mirror at the recorded revision](https://github.com/ritam413/Music-Mood-Classifier-/tree/3b29a3f47c669b7a0c992211d638641ca5079594/data/archive/MER%20Audio).

The dataset contains 900 thirty-second music clips, with 225 in each of four
valence/arousal quadrants: positive/high, negative/high, negative/low and
positive/low. Metadata and initial emotion assignments come from AllMusic;
the final quadrant classes were manually validated. These are categorical
labels, rather than continuous listener ratings of valence or arousal.

TuneConsole uses all 900 supplied clips, joined to artist/title metadata by
exact AllMusic recording ID. The metadata is CP1252-encoded; folder labels and
metadata agree. There are 664 artist groups.

4Q overlaps the expanded [MERGE](merge.md) release. Use one source version when
combining them, and exclude connected recordings/artists across evaluation
splits. The [Coimbra MIREX-like collection](coimbra.md) and original MIREX
benchmark are separate datasets.
