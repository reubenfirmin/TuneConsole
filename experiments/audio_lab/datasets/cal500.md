# CAL500

Source: the original UC San Diego CAL500 release, with 502 annotation rows and
500 supplied recordings. Four recordings are too short for ten-second inputs:
496 usable initially, 494 after protected identity exclusions in later fits.
Original terms are retained in the bundled Focus model's notice.

Use the original listener checkbox fractions for Reading, Studying and other
activities. The published activity matrix keeps a Yes fraction only when at
least two listeners select the activity; it does not implement the README's
stated 80% rule. Preserve both target versions. Omitted checkboxes in completed
responses mean unselected; explicit unknowns remain missing.

| Date / experiment | Result and decision |
| --- | --- |
| Oct 28, native activity audit | Raw-vote embedding macro AP .4171 versus median control .2746. Sparse-label MAE alone favored constants and concealed useful ranking. |
| Oct 29–30, direct Focus and #615 mapping | Reading/Studying heads retained useful signal; native emotion consensus and hybrid did not improve the direct procedure. See [Focus provenance](../models/focus.md). |
| Oct 30, #637/#638 | Embedding residuals retained signal beyond nine emotion directions, but incremental ranking gains were uncertain. Separate task slopes did not improve over pooled/offset controls. Same-song liking was associated with endorsement; familiarity failed the adjusted check. |
| Nov 1, #711 | Binomial and beta-binomial heads improved likelihood but lost ranking/lift; retain ridge. |
| Nov 1, #810/#815 | Chroma's 32-song gain failed the larger protected 494-song comparison; discard this recipe. |

The 494-song audit reconstructs 1,677 responses. Only 42 responses carry listener
IDs (13 people); unidentified listener dependence remains. Whole-song activity
judgments paired with short excerpts do not measure improved concentration.
