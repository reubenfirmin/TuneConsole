# Audio datasets

Each reference defines the published collection, its native labels and audio,
and the subset used by TuneConsole. Source links lead to publisher releases or
the exact acquired mirrors. Valence means emotional positivity; arousal means
activation. They are separate from activity suitability and listening outcomes.

| Dataset reference | Contents | Published source |
| --- | --- | --- |
| [CAL500](cal500.md) | Popular music with listener emotion, activity and semantic annotations | [UC San Diego](http://calab1.ucsd.edu/~datasets/cal500/) |
| [Emotify / Emotify+](emotify.md) | Felt and perceived emotion on overlapping music excerpts | [Emotify](https://www2.projects.science.uu.nl/memotion/emotifydata/), [Emotify+](https://data.mendeley.com/datasets/wbk8zr9bd2/1) |
| [PMEmo](pmemo.md) | Popular-music choruses with static and changing valence/arousal | [Author repository](https://github.com/HuiZhangDB/PMEmo) |
| [DEAM](deam.md) | Music excerpts and full songs with static and changing valence/arousal | [Publisher](https://cvml.unige.ch/databases/DEAM/) |
| [Soundtracks](soundtracks.md) | Overlapping film-music excerpt sets with dimensional and discrete emotion ratings | [OSF](https://osf.io/p6vkg/) |
| [MTG-Jamendo human judgments](jamendo.md) | Explicit human votes for seven mood and sound-character tasks | [Publisher repository](https://github.com/MTG/mtg-jamendo-dataset) |
| [ManyMusic-Stim v2](manymusic.md) | Natural and generated music windows with human valence/arousal ratings | [Zenodo v2](https://zenodo.org/records/23647077) |
| [Memo2496](memo2496.md) | Instrumental recordings with expert valence/arousal trajectories | [Figshare](https://figshare.com/articles/dataset/Memo2496/25827034) |
| [WCMED](wcmed.md) | Western classical excerpts ranked by valence/arousal | [Publisher](https://www.metacreation.net/projects/ccmed_wcmed_soundscape/) |
| [Mid-level musical properties](midlevel.md) | Musician judgments of seven perceptual properties | [OSF](https://osf.io/5aupt/) |
| [SiTunes](situnes.md) | Situational recommendation interactions with before/after mood | [Author repository](https://github.com/JiayuLi-997/SiTunes_dataset) |
| [Coimbra MIREX-like](coimbra.md) | Five tag-derived mood clusters on supplied clips | [Acquired mirror](https://github.com/ethanray123/AudioEmotionPredictionModel/tree/8bdd6492f520d76cc2fa74ff69885b2b2b9c5777/Audio%20and%20Lyric%20Sentiment%20Neural%20Network%20Regression/MIREX-like_mood) |
| [4Q](4q.md) | Four manually validated valence/arousal quadrant classes | [Publisher catalogue](http://mir.dei.uc.pt/downloads.html) |
| [VGMIDI](vgmidi.md) | Rendered video-game piano music with changing emotion annotations | [Author repository](https://github.com/lucasnfe/vgmidi) |
| [MERGE](merge.md) | Audio/lyrics with validated quadrants and separate tag-derived coordinates | [Zenodo v1.1.0](https://zenodo.org/records/13939205) |
| [EMMA previews](emma.md) | Emotion-evoking music previews with nine GEMS dimensions | [EMMA](https://musemap-tools.uibk.ac.at/emma/) |
| [AMG1608](amg1608.md) | Sparse whole-song listener valence/arousal ratings | [Publisher](https://amg1608.blogspot.com/) |
| [NTWICM](ntwicm.md) | Compilation-song identities with four raters' static emotion judgments | [Annotation file](http://openaudio.eu/NTWICM-Mood-Annotation.arff) |
| [MERP](merp.md) | Full songs with time-varying emotion and listener identities | [Publisher release](https://huggingface.co/datasets/amaai-lab/MERP) |
| [Moods and Activities](moods-and-activities.md) | Listener tags, activity endorsements and nominations; no supplied audio | [UK Data Service](https://reshare.ukdataservice.ac.uk/852024/) |
| [Help Me study!](help-study.md) | Study/listening episodes with context and concentration reports | [Zenodo](https://zenodo.org/records/10085104) |
| [Private library](library.md) | Developer annotations and captured measurements with recording lineage | Private account; no public release |

[Additional sources](leads.md) defines collections and studies without an acquired
aligned audio corpus. Experiment results and model decisions belong in the
[audio experiment history](../README.md); dataset pages contain definitions,
source URLs, label semantics, subset boundaries and material limitations.
