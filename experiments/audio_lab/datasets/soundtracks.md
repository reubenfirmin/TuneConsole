# Soundtracks

Source, audio and annotation downloads: [Eerola and Vuoskoski's film-music release](https://osf.io/p6vkg/).

Soundtracks contains film-music excerpts rated for dimensional and discrete
emotion. Set 1 supplies 360 excerpts and Set 2 supplies 110; the sets overlap.
Annotations provide eight references on a 1–9 scale: valence, energy, tension,
anger, fear, happiness, sadness and tenderness. Labels describe the supplied
excerpt, rather than the whole film or a listening benefit.

TuneConsole's combined source retains 470 annotation/audio rows with connected
film, recording and audio groups. This is not 470 independent recordings.
Set 2 includes an identical-excerpt pair (`010`/`095`) and different segments of
one recording (`084`/`088`); it cannot be an independent test set for Set 1.

Grouping depends on the task's exclusions: the Release comparison has 295
related components, while the [mid-level-property subset](midlevel.md) uses
the 360 Set 1 rows in 45 transitive film/audio components. These partitions are
distinct. Anger ratings describe expressed emotion, rather than cathartic or
therapeutic effects.
