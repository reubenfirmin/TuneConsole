# Soundtracks

Sets 1 and 2 supply 360 and 110 excerpts, with overlapping identities. Keep
related film/recording/audio groups together. Their eight native references
include valence, energy, tension, anger, fear, happiness, sadness and tenderness.
Labels describe the supplied excerpt; anger is not cathartic listening benefit.

Oct 28: Set 2 embedding MAE .1121 beat the training mean .1890 and acoustic-only
.1616. Attributes plus embeddings (.1133) and added pretrained moods (.1127)
did not improve the embedding control. Adding these heads to the 55-song local
diagnostic did not improve acceptable top choices (both 61.8%).

The expanded 470-row corpus is a common transfer reference for later specialists.
Release comparisons use 295 related components; mid-level-property work uses
the 360 Set 1 rows in 45 stronger transitive film/audio components. These
partitions and summary scores belong to different protocols.

Oct 30: fixed consensus improved Relax ranking; aggression/power blending
regressed Release; Uplift/Energize tradeoffs are preserved in their model logs.
Nov 1: seven human mid-level properties were predictable, but a predicted-property
bottleneck worsened every emotion error and augmentation failed all advancement
gates. The true-property oracle helped some tasks but is unavailable at inference.
